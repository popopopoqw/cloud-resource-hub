# 123云盘配置指南（网盘转存 + 我的网盘）

> 两个模块共用同一套凭据：**PanTransfer 资源转存**（分享链接解析/转存）与
> **我的网盘**（文件浏览/管理）。配置后自动从 Mock 切换为真实对接。

## 启用条件（凭据驱动）

`.env` 配置 `PAN123_ACCESS_TOKEN` 即接真实网盘；未配置走 Mock 演示；
`PAN_MOCK=true` 可强制 Mock（默认关闭，不再影响其他模块）。

```ini
PAN123_ACCESS_TOKEN=<开放平台 access_token>
# 可选：
# PAN123_API_BASE=https://open-api.123pan.com
# PAN123_CLIENT_ID= / PAN123_CLIENT_SECRET=（签名自动获取 token 尚未实现，预留）
```

## 获取 access_token 的步骤

1. 打开 [123云盘开放平台](https://www.123pan.com/a/dokuforopen)（open.123pan.com），
   注册开发者账号（需与你的 123云盘账号同主体）
2. **创建应用**：填写应用名/回调地址（任意），申请所需接口权限
   （`file:list`、`file` 管理、`share` 等，按模块需要）
3. 审核通过后，在应用的**调试/在线获取 token** 页面生成 access_token
   （或按官方文档的签名流程自行换取）
4. 复制 token 填入 `.env`，重启服务——启动日志出现
   `网盘：123云盘真实对接` 即生效

## 联调注意（首次接入必读）

「我的网盘」的文件管理接口（列表/新建/重命名/移动/回收站/直链/容量）与
分享解析/转存接口均按开放平台文档**预置实现、字段待校准**（代码中以
`TODO(联调)` 标注）。首次接入若某操作报错，把接口返回的错误信息提供给
维护者，通常是对着实际响应微调字段名即可。

## 能力对照

| 功能 | Mock 演示 | 真实（配置 token 后） |
|---|---|---|
| 我的网盘：浏览/新建/改名/移动/删除/下载/容量 | ✅ 演示文件树 | ✅ 需联调校准 |
| 转存工作台：解析分享链接 | ✅ 模拟解析 | ⚠️ 等开放平台开放分享接口 |
| 转存工作台：转存任务 | ✅ 模拟流程 | ⚠️ 同上 |
| 直链下载 | mock:// 链接 | ✅ 需联调校准 |

## token 有效期

access_token 有有效期（以开放平台文档为准，通常 30 天）。过期后表现为
接口 401/token 失效错误，需重新生成并更新 `.env`。ClientID/Secret 自动
换签名的实现（`internal/pan/pan123.go` RefreshToken TODO）待后续补充，
补齐后即可长期免维护。
