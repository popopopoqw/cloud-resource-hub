# 「我的网盘」模块设计方案

> 状态：**已决策，实施中**。2026-09-29 拍板：
> - **D1 深度**：L2 浏览 + 管理（新建/重命名/移动/删除回收站/直链下载/容量条）
> - **D2 账号**：单账号配置式（环境变量注入，与站点单账号模式一致）
> - **D3 联动**：本期不联动，独立成页（`#/drive`）；转存选择器联动后置

## 1. 功能定位

管理你自己的网盘（当前对接 123云盘，多网盘后期并行）：**浏览 → 整理 → 与转存/书库联动**。

```
我的网盘
├── 文件浏览：目录树导航（面包屑）、列表（名称/大小/类型/修改时间）、分页、按名搜索
├── 文件管理：新建文件夹、重命名、移动（弹目录树选目标）、删除（进网盘回收站）
├── 下载/预览：直链下载（302 到网盘直链）；图片/文本轻预览（可选）
├── 存储概览：容量用量条（已用/总量）
└── 联动（见 D3）：转存工作台目标目录选择器复用本模块目录树
```

## 2. 现状与依赖（重要）

| 事项 | 现状 | 影响 |
|---|---|---|
| 123pan 列目录 | ✅ `pan123.ListFiles()` 骨架已写好 | L1 只读浏览的核心调用已在 |
| access_token 签名 | ⚠️ 未实现（支持 `PAN123_ACCESS_TOKEN` 直接注入） | 与书库联调同批解决 |
| 管理类接口（建目录/改名/移动/回收站/直链/容量） | 开放平台均有对应端点，**方法名/字段需凭据联调校准**（同书库 TODO 模式） | 代码先就位，联调时微调 |
| 演示模式 | `PAN_MOCK=true` 下走 Mock 文件树（固定目录+文件，操作即时生效） | 不配凭据也能完整演示 |

## 3. 对接深度（决策点 D1）

| 档位 | 能力 | 工作量 | 依赖 |
|---|---|---|---|
| **L1 只读浏览** | 列目录 + 面包屑 + 分页 + 容量条 + 直链下载 | 小 | 列目录骨架已有 |
| **L2 浏览 + 管理**（推荐） | L1 + 新建/重命名/移动/删除（回收站） | 中 | 管理类端点联调 |
| **L3 + 上传** | L2 + 浏览器文件上传到网盘（分片上传流程） | 大 | 123pan 上传三步接口，最复杂 |

推荐 L2：管理能力是「网盘工具」的体感分水岭；上传（L3）的 123pan 分片协议复杂且书库→网盘链路可替代其大部分价值，后置。

## 4. 账号模式（决策点 D2）

| 方式 | 说明 |
|---|---|
| **单账号配置式（推荐）** | 沿用站点单账号模式：`PAN123_ACCESS_TOKEN`（或后期补签名后用 ClientID/Secret）环境变量注入，页面上即「我的网盘」 |
| 多账号切换 | 账号设置页绑多个网盘账号，进入模块先选账号；架构留口（accounts 表已有），实现和交互成本高 |

## 5. 联动范围（决策点 D3）

| 联动 | 说明 | 建议 |
|---|---|---|
| 转存目标目录选择器 | 转存工作台输入目标目录改为「从我的网盘目录树点选」，替代手输 `/来自：分享转存` | 本期做（小改动，体验提升明显） |
| 书库转存目标双选 | 书籍转存可选「R2/本地」或「直接进网盘」 | 后置（依赖网盘上传接口，即 L3） |
| 不联动 | 各模块独立 | 不推荐，重复造树 |

## 6. 架构设计

### 6.1 接口层：`pan.FS`（新接口，与 Provider 分离）

```go
// internal/pan/fs.go
type FS interface {
    ListDir(ctx, dirID int64, page int) (*DirListing, error)  // 文件+目录，分页
    Mkdir(ctx, parentID int64, name string) (int64, error)
    Rename(ctx, fileID int64, name string) error
    Move(ctx, fileIDs []int64, targetID int64) error
    Trash(ctx, fileIDs []int64) error                          // 网盘回收站，可恢复
    DownloadURL(ctx, fileID int64) (string, error)             // 直链，302 用
    Capacity(ctx) (used, total int64, err error)
}
```

- `*Pan123` 实现 `FS`；`Mock` 实现同一接口（演示文件树，操作内存生效）
- `Registry` 里按类型断言 `p.(FS)` 判断网盘是否支持文件管理（夸克等后期接入同理）

### 6.2 API（登录墙内）

```
GET  /api/v1/drive/list?dir=&page=&q=      目录内容（dir=0 根目录）
GET  /api/v1/drive/tree?dir=               子目录树（转存选择器复用）
GET  /api/v1/drive/capacity                容量
POST /api/v1/drive/mkdir   {parent_id, name}
POST /api/v1/drive/rename  {file_id, name}
POST /api/v1/drive/move    {file_ids[], target_id}
POST /api/v1/drive/trash   {file_ids[]}
GET  /api/v1/drive/download/{file_id}      302 直链
```

### 6.3 前端

- `MODULES` 登记 + `#/drive` 路由
- 布局：顶部面包屑 + 容量条 + 工具栏（新建/上传占位）；主体文件列表（图标/列表双视图可后置）
- 操作：行内「更多」菜单（重命名/移动/删除），移动弹层内嵌目录树（复用 /drive/tree）
- Mock 演示树：`/视频 /图书 /软件` + 若干文件，操作即时生效

### 6.4 数据层

网盘数据在云端，本地**不加表**；（可选）后期加「最近访问」记录表，本期不做。
