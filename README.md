# 资源中心（Resource Center）

一个面向个人使用的多源资源管理平台：从资源社区发现内容，解析 123 云盘分享，按分类一键转存到自己的网盘，同时提供网盘管理、电子书、Gmail 和 Cloudflare 监控等功能。

> 多源聚合 · 云端管理

## 核心功能

| 模块 | 能力 |
|---|---|
| 资源广场 | 获取 `pan1.me`、`123panfx` 的资源列表，支持分类、搜索、封面和论坛会话 |
| 一键转存 | 解析帖子中的 123 云盘分享，按影视类别转存并记录任务状态 |
| 我的网盘 | 分页浏览目录和文件，支持新建、重命名、移动、删除、下载和容量查询 |
| 书库 | Z-Library 搜索入口、书架和书籍转存，支持 Cloudflare R2 或本地存储 |
| Gmail 邮箱 | OAuth 只读授权、收件箱、搜索、邮件详情和附件下载 |
| Cloudflare 监控 | Workers、域名流量、R2 用量和访问趋势 |
| 账号设置 | 集中配置外部服务，保存前测试、加密存储并热生效 |

项目使用 Go 1.26+，前端通过 `go:embed` 内嵌，无需单独的前端构建环境；默认使用 SQLite 持久化用户、会话、任务、配置和检测状态。

## 硬件要求

| 资源 | 最低配置 | 推荐配置 |
|---|---|---|
| CPU | 1 vCPU | 2 vCPU |
| 内存 | 512 MB，并配置至少 1 GB Swap | 1 GB 以上，并配置 2 GB Swap |
| 磁盘 | 1 GB 可用空间 | 10 GB 以上，实际容量取决于 SQLite、日志和本地书籍文件 |
| 架构 | amd64 或 arm64 | amd64 或 arm64 |
| 网络 | 可访问资源论坛、123 云盘及已启用的外部服务 | 海外或网络连通性稳定的运行环境 |

最低配置适用于直接运行已构建的单二进制、单用户和低并发场景。如果需要在服务器上从源码编译、并发执行转存任务，或后续启用 Chrome/chromedp 自动登录，建议使用至少 **2 vCPU、2 GB 内存**。Cloudflare Tunnel 常驻运行时也需要为 `cloudflared` 和系统预留额外内存。

## 快速开始

```bash
cp .env.example .env
go test ./...
go build -o resource-center .
./resource-center
```

访问 [http://127.0.0.1:8080](http://127.0.0.1:8080)。

## 必备配置

首先修改 `.env` 中的站点登录账号，生产环境禁止使用程序默认密码：

```dotenv
AUTH_USER=admin
AUTH_PASS=请替换为高强度密码
```

使用资源转存和“我的网盘”时，推荐配置 123 云盘账号密码，以便自动获取并续期 Token：

```dotenv
PAN123_ACCOUNT=你的123云盘账号
PAN123_PASSWORD=你的123云盘密码
```

其他服务可以在登录后的“账号设置”页面中配置，也可以通过 `.env` 注入。站内保存的敏感配置会加密写入 SQLite。

完整配置、GitHub Actions、部署、API 和开发说明见 [docs 文档目录](docs/README.md)。
